环境共享说明

  • 一人可加入/创建多个团队，在上方团队列表中随时切换「当前使用」的团队；环境列表只显示当前团队的共享环境。
  • 在「环境列表」编辑环境时勾选「共享到我的团队」，成员即可在自己的环境列表看到并启动该环境；创建者可在此页用「环境使用授权」按成员精细授权。
  • 共享环境的Cookie/缓存：任意成员（含创建者）关闭窗口时自动经 AES-256-GCM加密 上传服务器，其他成员启动该环境时自动拉取解密使用，实现登录态互通；加密密钥按环境隔离，服务端无法查看明文。
  • 所有成员共享团队的打开次数：成员启动共享环境消耗团队创建者的套餐配额（每日/并发），上方显示团队共享用量。
  • 成员「克隆为私有」需创建者授权；共享环境仅创建者可编辑/删除。

本地自动化 API（兼容 Puppeteer / Playwright）

Base URL: http://127.0.0.1:8848　鉴权头：X-Local-Token: <设置页Token>

GET  /health                              健康检查
GET  /api/v1/profiles                     环境列表
POST /api/v1/profiles/:id/start           启动实例，返回 { wsEndpoint }（CDP WebSocket 地址）
POST /api/v1/profiles/:id/stop            停止实例
POST /api/v1/profiles/batch-start         { "ids": [1,2,3] }
POST /api/v1/profiles/batch-stop          { "ids": [1,2,3] }
GET  /api/v1/profiles/running             运行中实例
POST /api/v1/profiles/extensions          { "ids": [1,2], "extensions": ["C:\\ext\\dir"] }

Puppeteer 连接示例

const puppeteer = require('puppeteer-core');
const res = await fetch('http://127.0.0.1:8848/api/v1/profiles/1/start', {
  method: 'POST', headers: { 'X-Local-Token': '你的Token' }
}).then(r => r.json());
const browser = await puppeteer.connect({ browserWSEndpoint: res.wsEndpoint, defaultViewport: null });

Playwright 连接示例

const { chromium } = require('playwright');
const browser = await chromium.connectOverCDP(res.wsEndpoint);

技术限制说明

  • JS 层无法修改 TLS JA3/JA4 网络层指纹，该指纹由内核网络栈决定。
  • IP 与时区必须匹配：使用代理时请开启 GeoIP 自动匹配，否则 UA/GPU/时区/IP 地域互相矛盾易被识别。
  • 禁止大幅修改 Unix 绝对时间戳（本产品仅调整时区偏移展示，不篡改 Date.now()）。
  • SOCKS5 带用户名密码认证时 Chrome 原生不支持，建议使用免认证代理或 IP 白名单。
  • 本工具不提供绕过平台风控的功能，不承诺账号永不封禁。

Cookie 管理 ·

JSON 数组格式（兼容 EditThisCookie 导出）：每项含 name、value、domain、path，可选 expirationDate（秒级时间戳）、httpOnly、secure、sameSite。环境运行中可点「📥 读取浏览器Cookie」直接抓取浏览器内各网站的真实 Cookie（含登录后下发的 Cookie，打开弹窗时也会自动读取）；保存后下次启动该环境时自动注入，登录态直接生效。导入他人浏览器的 Cookie 后建议先点「🔧 一键自动修复」，自动处理域名、过期时间、SameSite 兼容、重复项等问题。

新建环境

单机模式与团队共享互斥；共享环境的Cookie/缓存全程AES-256-GCM加密传输与存储，服务端无法查看明文。

时区/语言/经纬度与代理IP绑定，不参与随机

参数需逻辑自洽：UA / 平台 / GPU / 时区 / 语言 / IP地域应互相匹配，否则易被网站检测。

启动实例时将通过此代理读取出口IP，自动填充对应时区/语言/经纬度（可在设置页关闭）。动态代理每次换IP后重启实例即自动更新。

💡 填写后，每次启动都会检测实际出口IP。若代理IP发生变化（如动态代理换IP），将阻止打开环境，避免在错误IP下操作。

数据存储：默认情况下Cookie/localStorage仅保存在本地磁盘；团队共享环境会加密云同步。勾选「单机模式」后该环境永远不上传、不共享。不同环境数据完全隔离。
